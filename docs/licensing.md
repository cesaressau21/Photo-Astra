# Licencia pendiente

La intención es publicar Photo Astra como software gratuito y open source.
GPL-3.0 es candidata; en este hito no se ha aplicado una licencia definitiva
al código del proyecto. No hay un archivo LICENSE que conceda todavía los
permisos de uso como proyecto open source: esa decisión sigue pendiente.
La publicación del código en GitHub no sustituye la elección de licencia.

El código y la interfaz de esta base son originales. No se han incluido
recursos, marcas ni código de Adobe Photoshop o Krita.

Qt y las herramientas descargadas conservan sus propias licencias y avisos
en las instalaciones locales. No se incluyen sus binarios en el repositorio.
Antes de publicar binarios se documentarán las versiones, licencias, fuentes
y avisos de todas las dependencias. Skia m144 está integrado desde su código
oficial; se conserva su licencia en `third_party/licenses/Skia-LICENSE.txt`.
OpenColorIO no está integrado. La configuración de Skia, revisión y procedencia
están descritas en `docs/skia.md`.
